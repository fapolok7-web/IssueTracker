---
description: How to save and push changes to GitHub
---
Step 1: Save your changes
Make sure all your files are saved.

Step 2: Open the terminal
You can use the terminal in your editor.

Step 3: Run the following commands

1. Check which files have changed:
```bash
git status
```

2. Add all changes to the staging area:
```bash
git add .
```

3. Commit the changes with a message (replace "Your message here" with a description of what you did):
```bash
git commit -m "Your message here"
```

4. Push the changes to GitHub:
```bash
git push
```
